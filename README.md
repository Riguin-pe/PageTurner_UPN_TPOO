# PageTurner

Modelo orientado a objetos en Java para una librería académica. Incluye las
clases del dominio, una demostración por consola y el diagrama UML en Mermaid.

## Ejecutar

Con JDK 21 instalado, desde la raíz del proyecto ejecute:

```powershell
javac -d out src\pageturner\*.java
java -cp out pageturner.PageTurnerApp
```

El diagrama está disponible en [docs/diagrama-clases.md](docs/diagrama-clases.md).
